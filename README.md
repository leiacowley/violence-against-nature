VIOLENCE AGAINST NATURE (V.A.N.)

An experimental browser-based neural network visualisation exploring emergent behaviour, signal propagation, and activity-dependent synaptic plasticity.

Overview

V.A.N. is a lightweight interactive neural-network simulation built with HTML, CSS, vanilla JavaScript, and the HTML Canvas API.

The project provides a visual sandbox for experimenting with connected nodes, signal activity, stimulation, network dynamics, and adaptive connection strengths.

It is an exploratory computational model, not a biologically complete simulation of the brain.

Features

* Animated neural network visualisation
* Signals propagating across network connections
* Interactive stimulation and activity controls
* Activity diagnostics and network metrics
* Chaos and overload controls
* Reset functionality
* Basic activity-dependent synaptic strengthening

Run locally

No build tools or package installation are required.

1. Clone or download this repository.
2. Open index.html in a modern web browser.

Technology

* HTML5
* CSS
* Vanilla JavaScript
* Canvas API
